BLOCKR Privacy Policy

Last updated: 18 September 2026
Summary: BLOCKR is designed to block ads, trackers, and intrusive webpage elements. BLOCKR does not sell user data and does not send browsing history, website content, or user activity to BLOCKR servers.

Information BLOCKR processes

To provide its blocking and page-cleaning features, BLOCKR may process the following information locally in your browser:

  • Web history: the current website/domain being viewed, so site-specific blocking and settings can work.
  • User activity: limited interaction data needed for user-requested features such as Element Zapper, including hover, click, or keyboard actions while that tool is active.
  • Website content: webpage elements and page structure needed to identify and remove ads, popups, trackers, and other unwanted content.

Local storage

BLOCKR stores settings locally in the browser, including protection preferences, per-site exceptions, custom blocking rules, Element Zapper rules, and local blocking statistics. These settings are used only to provide BLOCKR's features and persist your choices between browser sessions.

Data transmission

BLOCKR does not send your browsing history, website content, user activity, or locally stored BLOCKR settings to BLOCKR servers. BLOCKR does not operate an analytics or advertising backend that receives this information.

Data selling and sharing

BLOCKR does not sell user data. BLOCKR does not transfer user data to third parties for advertising, profiling, creditworthiness, lending, or purposes unrelated to BLOCKR's content-blocking functionality.

Remote code

BLOCKR does not execute remotely hosted code. Executable extension code is packaged with the extension.

Permissions

BLOCKR requests browser permissions required for its core features, including blocking advertising and tracking requests, applying site-specific protections, removing unwanted page elements, and running user-requested tools such as Element Zapper.

Changes to this policy

If BLOCKR's data practices change, this privacy policy will be updated before those changes are released where required.

Contact

For privacy questions about BLOCKR, please use the developer contact information provided on the BLOCKR Chrome Web Store listing.
